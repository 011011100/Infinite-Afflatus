# 交互规范

更新时间：2026-09-28。主画布交互第一版已实现；视频编辑、裁剪与素材子画布仍在设计阶段，尚未实现的操作不得在验收中标记为通过。

## 已确认：主画布只展示视频

画布对象是单视频卡片和组合卡片。创建 AI 镜头时可先有一个待生成的视频卡片，但参考图、提示词、分镜文本、模型参数不在主画布各自形成节点。

单视频和组合都可以在画布上移动。画布位置影响视觉布局；组合内部的片段列表决定播放顺序。不能通过每次读取画布横坐标来重新推算成片顺序。

## 已确认：左右贴合后合成一张卡片

两张视频卡片在左右边缘拼接后形成一个可整体拖动的组合。左边先播放，右边后播放；继续拼接时遵循同样的方向。

当前的拖动反馈：

1. 拖近可拼接边缘，出现清楚但轻量的吸附提示。
2. 松开前展示将形成的左右顺序；只靠近但未松手不修改组合。
3. 在有效位置松手后提交合并；移开或按 Esc 取消预览。
4. 合并后选中整个组合，保留每一段的镜头和素材引用。

第一版只支持两端追加，组合中间插入与内部重排后续评估。误拼接可撤销。当前尚无片段裁剪和分镜编辑数据。

## 已确认：只拆分选中的片段

在组合内单击一个片段后，「拆分选中片段」只将该片段移出组合，成为独立卡片。选中片段前后的连续片段分别保留为组合，不跨过拆分位置自动拼接。没有选中具体片段时不显示拆分入口，不能默认解散整个组合。

例如「蓝 + 绿 + 橙」中选中橙色，拆分后为「蓝 + 绿」与独立橙色；选中中间绿色，拆分后为独立蓝色、独立绿色、独立橙色。更长的「1 + 2 + 3 + 4 + 5」选中 3 后得到「1 + 2」、独立 3、「4 + 5」。若原组合只有两段，拆分后自然得到两张单视频卡片。

拆分后的各部分按原顺序从左到右排列，间隔 48 个画布像素；最左部分沿用原卡片标识和位置，保留对它的选择并清除片段选中状态。一次撤销恢复原组合、顺序和坐标，重做恢复此次局部拆分。

## 已确认：一个卡片对象只有一个播放按钮

**组合卡片是一个整体，只显示一个播放按钮。禁止「两段缩略图各一个播放按钮，再加组合播放按钮」。**

播放按钮可以在卡片悬浮工具中，也可以在卡片本体；两处不能同时重复展示。双击和快捷键复用同一个预览功能，不添加额外按钮。选择具体放置位置时以可发现性和紧凑程度为准。

- 播放组合时，从左到右依次播放各段经过裁剪后的内容。
- 单击组合中的某一段是选择该段，不立即播放。
- 点击唯一播放入口打开对应对象的放大预览，控制区显示一次。
- 关闭预览时停止其播放，回到原画布缩放、位置和选择状态。
- 主画布以静态缩略图为主，不让所有卡片自动播放。

原型必须区分「连续切换视频」和「无缝音画衔接」。前者可先验证交互；后者需要真实媒体解码和预加载测试，不能仅凭两段视频都能播放就宣称完成。

## 选择、播放与手势

| 操作 | 建议结果 |
| --- | --- |
| 单击空白 | 清除选择 |
| 单击卡片 | 选中卡片，显示轻量操作工具 |
| 单击组合中的片段 | 明确选中该片段，仍只保留一个组合播放入口 |
| 拖动卡片主体 | 移动卡片／组合，不误触播放或编辑 |
| 双击卡片 | 打开播放浮层；组合从第一段开始按顺序播放 |
| 长按组内片段 0.7 秒后松开 | 按当前局部拆分规则拆出该片段；保持前后各自连续组合 |
| 移动超过 5 个屏幕像素、提前松开、Esc、切走窗口 | 取消长按拆分；拖动继续按原规则处理 |
| 使用裁剪图标 | 编辑选中的单个片段 |
| Esc | 取消拖动预览或退出当前临时操作，避免一次清空多层状态 |

工具按钮、视频进度条和裁剪控件应阻止画布拖动事件，避免调整参数时把整个卡片拖走。

## 交互与快捷键设置

设置分为「交互与快捷键」与「保存与存储」。长按拆分默认开启，可关闭；现有播放和拆分按钮保留。长按提示延迟 150 毫秒出现，避免普通单击闪烁；完成进度后显示「松开拆分」，松开之前仍可移动取消。

| 功能 | macOS 默认 | Windows 默认 |
| --- | --- | --- |
| 播放选中卡片／组合 | 空格 | 空格 |
| 拆分选中片段 | ⌘ Shift G | Ctrl Shift G |
| 撤销 | ⌘ Z | Ctrl Z |
| 重做 | ⌘ Shift Z | Ctrl Shift Z |

点击按键录入新组合，支持清除单项或恢复默认，点击「保存设置」后生效。键名及识别按当前系统区分：Windows 只显示 Ctrl，macOS 显示 ⌘，不要求 Windows 使用 Command。配置保存在应用自己的 SQLite，与项目目录分离，重新打开及迁移项目保存目录后保留。重复快捷键、系统／文本编辑保留组合及不支持的按键会提示并拒绝保存。

画布快捷键在文本输入、输入法组合、弹窗、拖动和保存期间不触发；长按键不会重复执行。Esc 固定用于关闭弹窗、取消拖动或清除选择。快捷键只在本应用画布中生效，不注册系统全局快捷键。

## 镜头编辑

镜头内部承载分镜文本、参考图以及生成结果。已确认两种页面并存：当前视频的操作使用大浮层；内部图片生成与其他素材制作进入对应子画布，输出所选素材回到镜头。返回主画布时保留视口和选中状态。当前仅预览浮层已实现，编辑浮层与素材子画布待实现。

以下为建议的结果管理规则：

- 多次生成的候选结果保留在镜头内部，主画布仅展示当前采用的视频。
- 用户明确选择「采用」才替换当前版本。
- 编辑文本和参考图不会自动发起付费生成；需要明确的生成动作。
- 正在生成或生成失败时，已采用的旧版本仍可预览。
- 更换素材后重新检查时长、截取范围和裁切区域；不能沿用越界参数。
- 关闭编辑视图后恢复主画布状态。草稿保存和放弃策略需在该页面设计时确定。

## 视频裁剪

「时间截取」和「画面裁切」是两个不同操作，都需要支持。

时间截取设置起止时间；画面裁切设置可视区域或比例。建议在较大的预览中操作，主画布保留紧凑的视频卡片。

建议采用非破坏编辑：保存编辑参数，保留源视频。进入裁剪时使用临时草稿，应用后更新卡片及组合总时长，取消时恢复进入前的参数。

组合总时长按当前各段的有效时长相加，不使用原始源文件总时长。预览与导出必须使用同一份片段顺序和编辑参数。

- [ ] 两个已有组合合并时，各自内部顺序不变；取消吸附不改变任何数据。
- [x] 组合卡片只有一个可见播放入口，包括悬浮／选中状态。
- [x] 拆分选中片段后，前后各自保持连续组合与顺序，不跨段自动拼接，撤销／重做可恢复。
- [ ] 顺次预览遵守有效截取范围，关闭后停止音频并恢复画布视口。
- [ ] 选中、拖动、播放、进入镜头编辑不会相互误触。
- [ ] 每段仍能找到自己的分镜和参考图，候选版本不散落到主画布。
- [ ] 时间截取和画面裁切可应用、取消，源素材不被覆盖。
- [ ] 合并、拆分、裁剪的撤销行为可恢复数据；具体撤销范围以原型方案为准。
- [x] 没有导入或生成视频时，空状态不会伪装成已生成的真实结果。

已验证的部分链路：原片顺次播放、Esc 关闭浮层、片段选择不触发播放、整体拖动、拆分与撤销／重做、重新打开恢复组合和坐标。涉及裁剪与镜头编辑的验收项保持未完成。Esc 取消拖动已实现，但本轮自动桌面操作未覆盖按住鼠标期间的 Esc；需人工补充验收。
