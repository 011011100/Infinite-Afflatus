# 交互规范

更新时间：2026-10-04。主画布交互第一版、全窗口播放与简单时间裁剪已实现。镜头素材子画布已实现素材节点、框选组合、跨组合并、长按拆出、悬浮组合编辑、Seedance／Seedream 参数、文生图／图生图组合及每镜头保存；云端生成仍待接入，尚未实现的操作不得在验收中标记为通过。

## 已确认：主画布只展示视频

画布对象是单视频卡片和组合卡片。创建 AI 镜头时可先有一个待生成的视频卡片，但参考图、提示词、分镜文本、模型参数不在主画布各自形成节点。

单视频和组合都可以在画布上移动。画布位置影响视觉布局；组合内部的片段列表决定播放顺序。不能通过每次读取画布横坐标来重新推算成片顺序。

## 已确认：左右贴合后合成一张卡片

两张视频卡片在左右边缘拼接后形成一个可整体拖动的组合。左边先播放，右边后播放；继续拼接时遵循同样的方向。

当前的拖动反馈：

1. 拖近可拼接边缘，出现清楚但轻量的吸附提示。
2. 松开前展示将形成的左右顺序；只靠近但未松手不修改组合。
3. 在有效位置松手后提交合并；移开或按 Esc 取消预览。
4. 合并后选中整个组合，保留每一段的镜头和素材引用。

第一版只支持两端追加，组合中间插入与内部重排后续评估。误拼接可撤销。拼接与拆分保留片段入出点，分镜编辑数据尚未实现。

## 已确认：只拆分选中的片段

在组合内单击一个片段后，「拆分选中片段」只将该片段移出组合，成为独立卡片。选中片段前后的连续片段分别保留为组合，不跨过拆分位置自动拼接。没有选中具体片段时不显示拆分入口，不能默认解散整个组合。

例如「蓝 + 绿 + 橙」中选中橙色，拆分后为「蓝 + 绿」与独立橙色；选中中间绿色，拆分后为独立蓝色、独立绿色、独立橙色。更长的「1 + 2 + 3 + 4 + 5」选中 3 后得到「1 + 2」、独立 3、「4 + 5」。若原组合只有两段，拆分后自然得到两张单视频卡片。

拆分后的各部分按原顺序从左到右排列，间隔 48 个画布像素；最左部分沿用原卡片标识和位置，保留对它的选择并清除片段选中状态。一次撤销恢复原组合、顺序和坐标，重做恢复此次局部拆分。

## 合并与拆分过渡

合并、局部拆分及其撤销／重做使用约 440 毫秒的平滑过渡。缩略图从当前可见位置移动并调整宽度，卡片底部的短连接随间距收拢或拉细断开，形成轻量的水滴粘连感；视频和文字不应用模糊滤镜。长组合只过渡当前可见范围，完成后恢复横向滚动。

保存成功后才播放过渡，保存失败不展示成功效果。动画不延迟数据保存，也不锁住下一次操作；新的点击、拖动或视口操作结束当前过渡，键盘撤销／重做从当前画面接续。系统开启「减少动态效果」时直接显示最终布局。动画不改变片段顺序、拆分边界或最终坐标。

## 页面与控件过渡

项目首页和画布内容、镜头子画布、视频编辑页使用 250 毫秒淡入及 8 像素轻移；返回时全窗口页在 150 毫秒内淡出，保留底层画布位置。镜头子画布先确认保存成功，再退出；保存失败恢复可编辑状态。关闭时立即停止媒体和接收编辑，重复点击不重复保存或关闭；打开途中关闭从当前画面接续。

设置分类和分辨率复用滑动选中底色；设置内容轻微淡入，切换分类保留尚未保存的输入。右键菜单从触发位置轻微缩放展开，退出更快。弹窗的关闭图标、取消、保存成功和添加素材统一经过关闭过渡；组合浮层的遮罩和顶部控件随面板淡入淡出。组合完成仍留在画布，只有手动展开才显示编辑浮层。

新增界面过渡复用 `styles/motion.css` 的时长与缓动，不引入动画依赖。键盘触发和系统「减少动态效果」即时呈现。持续拖动、裁剪、播放指针及视频帧切换不叠加这些动画，避免操作与画面不同步。

## 已确认：一个卡片对象只有一个播放按钮

**组合卡片是一个整体，只显示一个播放按钮。禁止「两段缩略图各一个播放按钮，再加组合播放按钮」。**

播放按钮可以在卡片悬浮工具中，也可以在卡片本体；两处不能同时重复展示。双击和快捷键复用同一个预览功能，不添加额外按钮。选择具体放置位置时以可发现性和紧凑程度为准。

- 播放组合时，从左到右依次播放各段经过裁剪后的内容。
- 单击组合中的某一段是选择该段，不立即播放。
- 点击唯一播放入口打开对应对象的放大预览，控制区显示一次。
- 关闭预览时停止其播放，回到原画布缩放、位置和选择状态。
- 主画布以静态缩略图为主，不让所有卡片自动播放。
- 缩略图在进入可见范围或邻近区域时读取，离屏后延迟释放显示位图，保留卡片的尺寸、选中和手势目标；拆合过渡期间保留已画好的内容。键盘焦点和正在按住的卡片保持预览，单纯选中不保留所有离屏位图。全窗口编辑或镜头子画布遮住主画布时，背景停止读取并释放显示位图；返回时优先复用缓存。详见 [媒体资源边界](media-performance.md)。

预览使用双播放器缓冲，提前加载下一段。等待期间保留当前画面，首帧可用才切换并更新片段高亮；加载失败保留旧画面并提供错误提示。任意跳段同样遵守此规则，音量、静音和倍速连续，关闭时取消等待及播放。

拖动播放指针时，指针与时间读数先跟随目标位置，当前片段标记仍以已经准备好的视频为准。同一片段每次完成一次解码，再处理最新目标，中间已过时的位置不排队；跨片段立即切换定位任务，松手优先定位最终位置。暂停拖动期间保留当前与最近使用的另一段，来回定位复用已加载的播放器；恢复连续播放后再预加载下一段。首次打开编辑页时后台生成最长边 540px、密集关键帧的代理，拖动播放指针及裁剪边界时优先使用代理；松手或停止移动 150 ms 后定位原片，对应帧就绪后才替换画面。原片与代理各保留两个复用缓冲（最多四个视频元素）；连续拖动不向原片反复发送定位请求。新输入取消过时的高清恢复；代理未准备好或失败时使用原片，正常播放与音频始终来自原片。

原型必须区分「连续切换视频」和「无缝音画衔接」。前者可先验证交互；后者需要真实媒体解码和预加载测试，不能仅凭两段视频都能播放就宣称完成。

## 选择、播放与手势

| 操作 | 建议结果 |
| --- | --- |
| 单击空白 | 清除选择 |
| 单击卡片 | 选中卡片，显示轻量操作工具 |
| 单击组合中的片段 | 明确选中该片段，仍只保留一个组合播放入口 |
| 拖动卡片主体 | 移动卡片／组合，不误触播放或编辑 |
| 双击卡片 | 进入全窗口播放与编辑页；组合从第一段的入点开始按顺序播放 |
| 长按组内片段 0.7 秒后松开 | 按当前局部拆分规则拆出该片段；保持前后各自连续组合 |
| 移动超过 5 个屏幕像素、提前松开、Esc、切走窗口 | 取消长按拆分；拖动继续按原规则处理 |
| 在编辑页选中片段并拖动两端 | 调整该片段入点与出点，松手保存 |
| Esc | 取消拖动预览或退出当前临时操作，避免一次清空多层状态 |

工具按钮、视频进度条和裁剪控件应阻止画布拖动事件，避免调整参数时把整个卡片拖走。

## 交互与快捷键设置

主画布顶部不常驻展示操作说明，只在吸附拼接或保存进行中显示当前状态。设置分为「交互与快捷键」与「保存与存储」。长按拆分默认开启，可关闭；现有播放和拆分按钮保留。长按时在选中片段中央浮现 64 像素圆环，顺时针填满；完成后稍微放大并切换为勾选图标。卡片内不展示文字横条，操作说明保留在设置与读屏提示中。圆环延迟 150 毫秒出现，避免普通单击闪烁；随后用 220 毫秒从 88% 大小淡入，松开或取消时用 160 毫秒缩小淡出。退出过程独立于卡片，拆分立即执行，圆环继续完成退场；提前取消从当前进度平滑退出。系统开启「减少动态效果」时跳过缩放与淡入淡出。松开之前仍可移动取消。

| 功能 | macOS 默认 | Windows 默认 |
| --- | --- | --- |
| 播放选中卡片／组合 | 空格 | 空格 |
| 拆分选中片段 | ⌘ Shift G | Ctrl Shift G |
| 撤销 | ⌘ Z | Ctrl Z |
| 重做 | ⌘ Shift Z | Ctrl Shift Z |

点击按键录入新组合，支持清除单项或恢复默认，点击「保存设置」后生效。键名及识别按当前系统区分：Windows 只显示 Ctrl，macOS 显示 ⌘，不要求 Windows 使用 Command。配置保存在应用自己的 SQLite，与项目目录分离，重新打开及迁移项目保存目录后保留。重复快捷键、系统／文本编辑保留组合及不支持的按键会提示并拒绝保存。

画布快捷键在文本输入、输入法组合、弹窗、拖动和保存期间不触发；长按键不会重复执行。Esc 固定用于关闭弹窗、取消拖动或清除选择。快捷键只在本应用画布中生效，不注册系统全局快捷键。

## 镜头编辑

主画布「新建镜头」创建待生成镜头卡片并打开内部素材子画布；已有视频通过「编辑镜头素材」进入，组合中的视频需先明确选中片段。双击已有视频继续进入播放与裁剪页。

子画布中，文本直接编辑，图片、视频、音频和文本文件可从本地导入或选择项目素材。左键拖动空白区域平移画布，右键拖动框选多个卡片；框选松手后不弹菜单，再右键单击选择「生成视频」组成生成组。成组与合并已有组后留在画布并选中新组，不自动打开编辑层；点击组标题或右键菜单「展开编辑」时，组合才从原位置飞入悬浮编辑层，原画布保留在背景：左侧以圆弧排列素材，滚轮或上下按钮切换；中间一张大卡片容纳独立文本块；右侧为 Seedance 参数。收起时沿原方向返回。画布上的组仍可整体移动或解除组合；解除后保留绝对位置。单独卡片也可成组，不要求凑齐所有类型。空格拖动或鼠标中键平移，滚轮缩放；Windows 使用 Ctrl、macOS 使用 ⌘ 加选。

已有组可以和独立卡片或其他组一起框选，通过右键「合并成组」合并全部选中素材，去重并移除空组框。合并参数优先沿用所选组中当前展开的组，否则沿用最左侧组。长按组内卡片的非交互区域，圆环完成后松手只拆出该卡片；保留其他成员与组参数，文字输入、媒体控件、按钮、移动或取消不触发拆出。长按沿用设置中的开关与主画布 700 ms 阈值，右键也提供「拆出卡片」。

拖动组外的独立素材卡片，让指针在已有组内停住时，目标组高亮，150 ms 后出现蓝色圆环。连续停留 700 ms，圆环变为确认勾选；保持按住不会加入，松手才合并，与长按分离一致。共用 5 个屏幕像素的移动容差：倒计时期间继续移动则重新等待；确认后继续拖动取消本次合并，即使仍在组内停住也不自动重新确认，需要重新拖入。提前松手、移出、Esc、指针取消、失焦、关闭页面或禁止编辑时取消；倒计时中换到另一组重新计时。加入后选中目标组并保持收起，保留目标组标识、位置、参数及原成员坐标，新卡片按顺序追加到空位，必要时扩展组框。标签和组框不触发悬停加入，超过 32 张素材上限的组不接受加入；框选后的组间合并继续使用原右键操作。

悬浮编辑中，文本块标题长按 700 ms 后拿起，跟随指针移动，其余块让位。组内松手保存顺序，拖出中间卡片边界 20 px 后提示「松手移回画布」，松手只移出该块。提前移动属于普通操作；仅按住后原地松手、Esc、指针取消、失焦与窗口尺寸变化不提交。按下 150 ms 后在文本块上浮现蓝色圆环，填满至 700 ms 时拿起；提前松开缩小淡出。拿起时显示拖出提示，越界后浮动块与提示变蓝；拖回文本区可继续排序。松手移出后缩小淡出，并显示「已移回画布」与「查看」入口，保持当前编辑打开；点击查看收起组合，必要时调整画布使独立卡片可见。正文支持正常选字和输入；另有上移、下移、移回画布按钮和手柄方向键。长列表靠近内部上下边缘自动滚动。无文本时补一个空块，已达 32 张上限时需先移出素材。

每个镜头独立保存子画布的视口、坐标、文本块内容与顺序、生成组参数。文本文件的编辑保存在项目引用中，不改写源文件。已有视频按素材 ID 关联镜头，主画布拼接或拆分不会丢掉镜头草稿。移除素材卡只解除引用，保留项目文件。返回主画布前等待保存，保存失败留在子画布并提供重试。完整交互和阶段边界见 [镜头素材子画布](video-generation.md)。

导入本地参考素材时，顶部临时显示当前文件、序号、实际接收字节、已完成数量及「取消导入」。取消后保留已完整接收的素材，提示未完成数量；失败项单独显示原因。导入期间仍可返回，离开流程先停止接收，再把已完成素材引用和编辑内容保存到原镜头，成功后退出；不会为了显示进度新增常驻面板。

素材子画布和组合编辑顶部提供共用的撤销／重做按钮。每个镜头各自保留本次项目会话的编辑历史，收起后再打开仍可撤销；退出项目或重启应用后不保留历史。撤销可以恢复文本内容、卡片与组的拆合、素材引用、文本顺序、参数、标签、卡片尺寸和位置。连续输入文字或调整同一对象参数、颜色会合并为一个编辑步骤，拖动与调整尺寸在松手后各记一步。导入素材的撤销只移除画布引用，项目中的文件继续保留。历史不回退画布视角、镜头在主画布的位置或关联视频。

素材画布使用设置中的撤销／重做快捷键，只在该画布获得焦点时响应；文字输入、输入法、弹窗、按住指针拖动和长按期间不响应。自定义为空格时，已聚焦的按钮仍保留空格激活行为。悬浮组合编辑使用顶部按钮撤销，撤销移除当前组时自动收起。展开时自动补的空文本不单独记入历史，撤销不会触发反复补块。恢复后的内容继续自动保存，返回主画布前等待保存完成；保存失败保留已恢复的草稿供重试。

以下为建议的结果管理规则：

- 多次生成的候选结果保留在镜头内部，主画布仅展示当前采用的视频。
- 用户明确选择「采用」才替换当前版本。
- 编辑文本和参考图不会自动发起付费生成；需要明确的生成动作。
- 正在生成或生成失败时，已采用的旧版本仍可预览。
- 更换素材后重新检查时长、截取范围和裁切区域；不能沿用越界参数。
- 关闭编辑视图后恢复主画布状态。草稿保存和放弃策略需在该页面设计时确定。

## 图片生成

图片与视频共用镜头素材子画布，不新增独立页面。选中独立文本／图片卡片后，右键菜单和底部操作栏都提供「生成图片」；文本文件也作为提示文本。组外图片仍可作为视频参考。成组后留在画布，外框标为「图片生成」，手动展开才显示原画布上的悬浮编辑：左侧参考图轮盘、中间图片描述文本块、右侧 Seedream 参数。没有参考图时为文生图，加入图片后为图生图；拆出最后一张图片后回到文生图，不修改文本及参数。只有图片时展开自动补一个空文本块，反复打开不重复添加。

图片组复用视频组的移动、尺寸调整、重命名、文本排序、拆出和同类组合并；悬停加入仍是圆环完成后确认、松手才加入、继续移动取消。图片组只接受文本与图片，最多 14 张参考图，包含文本最多 32 个节点；视频、音频和不可用的引用不可加入图片组。图片组与视频组不直接合并，避免覆盖不同类型参数；可先拆出需要复用的卡片再加入目标组。同类型合并沿用原参数继承规则。

右侧先支持 Seedream 5.0 Lite／4.5、画面比例与分辨率。默认 5.0 Lite、1:1、2K；5.0 Lite 可选 2K／3K／4K，4.5 可选 2K／4K，从 3K 切到 4.5 时回到 2K。按单张图片草稿设计，尚未接入云端提交，不展示模拟结果。各组的类型与参数独立自动保存，旧版没有类型的组仍按视频读取并保留原始字段。参数依据和验证边界见 [图片生成交互](image-generation.md)。

## 视频裁剪

「时间截取」和「画面裁切」是两个不同操作，都需要支持。

时间截取已整合进全窗口播放与编辑页。底部一条轨道按各段有效时长比例排列，展示秒数、缩略图和播放指针；轨道卡片内不叠加文件名、编号或文字底部遮罩，片段名称保留在无障碍标签中。当前播放段用顶边标记，选中编辑段显示边框与两侧手柄。点击片段选中并定位，拖动时间刻度可跨片段定位。

轨道缩略图按源视频的不同时间取帧，采样间隔随缩放密度调整。只解码可见范围及两侧少量预读区域，逐步填充并缓存；滚动或缩放后取消过时工作，关闭编辑页释放缓存和解码器。缩略图采样使用独立播放器，不改变上方预览的位置。

时间尺保留带时间标签的长刻度，未满一分钟显示 `58`、`59`，不带 `s` 单位；满一分钟后显示 `1:00`、`1:02`，分钟不补零、整秒不带小数；放大到半秒刻度时保留必要的小数，如 `1:02.5`。间隔内加入短刻度，按缩放密度分为 5 或 10 小格，短刻度至少相隔 10 个屏幕像素。空间足够时，中间刻度略长，便于判断半格位置。时间尺铺满轨道宽度，片段结束后的空白处也继续显示时间和小刻度，随缩放更新。延伸刻度不增加组合时长，点击超过末尾的位置仍定位到实际末尾；小刻度不新增吸附。

两端拖柄收在卡片内部，以细长的白色圆角竖条表示，取消外侧突出的蓝色块。鼠标悬停片段时用 150 毫秒淡入，移开用相同时长淡出，不因选中而常驻；只改变透明度，不移动手柄位置。可直接拖动悬停片段的边缘并自动选中，拖动期间保持显示；键盘聚焦手柄或系统开启减少动态效果时即时切换。可点击区域大于竖条本身，短片段的左右命中区域仍分开，避免拖错另一端。

拖动任一裁剪手柄靠近窗口左侧或右侧时，轨道向对应方向自动滚动；越靠近边缘速度越快，鼠标停住也可持续裁剪，无需松手重抓。快速拖动时按实际裁剪边界即时补足滚动距离，让正在拖的边缘留在视口内侧，不受停留滚动的速度上限限制；补偿滚动不重复计入裁剪量。只按住未移动时不启动；移回内部、松手、取消或失焦立即停止。恢复更早／更晚的素材时临时预留滚动空间，松手收回多余空白，取消恢复原范围及坐标基准。源片起止点和最短保留时长限制仍生效；普通悬停与播放头拖动不触发此行为。

拖到源片起止点或最短保留时长后，继续朝受限方向拉动时，当前竖条向拉动方向轻微弯曲，卡片内侧边缘出现系统主题蓝色的柔和渐变高亮。形变随超出距离增加而逐渐减缓，最多约 4 个屏幕像素，短片段相应缩小；保持鼠标不动时保留反馈，松开后约 200 毫秒回弹。卡片边界、缩略图与裁剪数值不越界，反向拖动立即恢复裁剪，不要求先走完超出距离。回弹不阻塞下一次操作；系统开启减少动态效果时只显示边缘高亮。

播放与轨道工具合并为一行，下方直接接时间轨道：左侧为播放与当前时间／总时长，右侧为静音、「恢复原片」、缩小按钮、缩放百分比、放大按钮。控制栏不展示文件名和片段序号，也不再单列重复的片段数量、总时长或选中片段的入出点和保留时长。恢复只作用于选中片段，未裁剪时禁用。

拖动手柄即时预览对应边界，松手自动保存。入点向内拖动时左边缘向右收缩、右边缘不动；出点向内拖动时右边缘向左收缩、左边缘不动。相邻片段随对应一侧移动，刻度与播放指针保持对齐；轨道比例只随主动缩放或窗口尺寸变化，松手不重新缩放或跳位。保存串行排队，手柄可连续操作，旧保存回执不覆盖新草稿。Esc、窗口失焦、窗口缩放和指针取消放弃本次草稿。两端不能交叉或超出源视频，通常至少保留 0.1 秒；极短原片允许保留整段。聚焦手柄后方向键微调 0.1 秒，Shift + 方向键调整 1 秒。「恢复原片」恢复该片段完整范围。

完成的裁剪先保护独立恢复副本，再提交项目。意外退出后显示原范围与恢复范围，明确确认才恢复；当前卡片或原素材变化时保持副本并拒绝覆盖。未松手的预览不保护，恢复不改源文件。项目改名沿用原弹窗，恢复名称只填回输入，点击保存才改名。详见 [项目名称与裁剪恢复](project-edit-recovery.md)。

非破坏编辑：只把源视频相对秒数保存到项目 SQLite，源文件不变。每次松手产生一步撤销，编辑页复用设置中的播放／撤销／重做快捷键，并按系统区分 Cmd/Ctrl；编辑页不会撤销画布的拼接与移动。返回画布后继续使用同一会话历史。保存失败恢复已保存范围并显示错误；迁移期间可播放，不能修改裁剪。

缩略图固定在源素材的对应位置：拖动头部时遮掉左侧内容，保留部分的位置与大小不变，不在新边界重新铺图。两端手柄的命中区域始终分开，即使片段缩到最短也能拉回。轨道打开时以当前组合的有效 0 秒为起点，不把已裁掉的源片入点累加为空白。放大后只滚动有效内容范围；拖动裁剪期间临时保留达到的最大宽度，保证手柄持续跟随鼠标，松手后收回多余空白并在必要时约束视口。播放头顶部有独立的透明拖动区域，可直接抓取，键盘方向键及 Home／End 与刻度定位共用组合时间。播放超出当前可视范围时，轨道跟随播放头。

组合总时长等于各段有效时长之和。播放只从每段入点到出点，预加载下一段的入点；等待时保留原画面。裁剪参数随拼接、拆分保留。当前尚未接入 FFmpeg 导出、画面裁切、中间切开或片段重排，后续导出必须复用相同顺序和入出点。

## 素材卡片尺寸与标签定位

镜头子画布的文本和素材卡片，顶部标题旁提供铅笔按钮；图片等素材的默认标题为类型名称，重命名后在此显示自定义名称，底部继续展示原文件名。Enter 或失焦保存名称，Esc 取消；空名称不覆盖原名。重命名只影响当前卡片，项目素材库、其他镜头引用和磁盘文件名保持独立。选中卡片后右下角显示缩放手柄，可连续放大或缩小；正文和媒体预览随卡片尺寸变化。手柄支持方向键微调，Shift 加速；Esc 或失焦取消本次拖动。尺寸随镜头保存，重新成组按各卡片实际尺寸排列，组内放大时外框随之扩展。

工具栏或空白处右键菜单可添加「标签」。标签有自定义名称、颜色与固定按钮；固定后不响应拖动，但仍可重命名、改色、解锁和删除。标签是当前镜头的定位标记，不作为生成输入，不加入生成组；各镜头分别保存。

默认按住 `L` 显示标签位置，松开隐藏。屏幕外标签在相应边缘显示带颜色、名称的小气泡，宽度随文字收紧，长名称省略；方向箭头放在气泡朝向目标的外侧。相近方向的气泡错开排列并为箭头留出间距，屏幕内标签直接就地显示。也可点击右上角定位按钮开关气泡。点击气泡后先围绕当前视野缩小，再平移到标签，最后恢复跳转前的缩放比例；标签落在画布中心。拖动、滚轮或 Esc 可打断跳转，启用减少动态效果时直接定位。文字输入、素材选择弹窗和组编辑打开时不触发定位快捷键。

「设置 → 画布快捷键 → 按住定位标签（素材画布）」支持修改、禁用和恢复默认。macOS 的组合键使用 ⌘，Windows 使用 Ctrl；升级旧设置时保留原按键，如旧操作已占用 `L`，新增定位键保持未设置，避免抢占。

## 本地交付与离开前保存

播放与编辑页右上角提供「导出视频」，输出当前单卡片／组合已保存的顺序与裁剪；打开导出弹窗暂停播放，弹窗内按键不穿透到编辑页。导出任务可收起并从应用顶栏继续查看、取消、重试或定位完成文件。

项目顶栏「项目备份」先展示预计大小与素材数量，再选择创建独立副本或导出 `.afflatus` 项目包；首页导入项目包并进入新项目。项目包与成片入口分开，已有文件不覆盖。

返回首页、关闭窗口和退出应用先提交镜头、裁剪、视口和在途素材引用；保存失败保留页面与草稿并提供重试，不把未保存内容静默丢弃。详细状态和边界见 [本地创作交付](local-delivery.md) 与 [离开前保存](saving-on-leave.md)。

救援文件导入放在「设置 → 保存与存储」，不新增画布按钮。选择文件后预览原项目、类型和影响范围，点击「导入为恢复副本」只添加独立副本；不切换项目、不自动保存或覆盖当前输入。当前项目的已有恢复提示随后更新，再通过原有名称／裁剪／镜头恢复操作处理，冲突和编辑锁继续生效。切换设置页或取消使未确认预览失效，已经明确确认的导入完成后仍刷新对应恢复列表。细节见[导入恢复文件](rescue-import.md)。

启动时原目录改名或移动，故障提示仅在原资料可核实时提供「重新定位原项目目录」。先选择目录，再显示原位置、当前位置、项目及待保存任务；默认和 Esc 都取消确认，明确「确认位置并重新打开」后才重新打开项目库。取消选择、取消确认或检查失败均回到原故障提示，不打开空白首页。应用退出后迟到的选择不触发定位，已确认开始的磁盘提交先完成再退出。此入口不出现在画布或运行中的编辑故障提示中；现有未保存输入仍受原有保存与重试流程保护。
