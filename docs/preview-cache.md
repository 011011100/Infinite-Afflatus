# 预览缓存检查与清理

入口在「设置 → 保存与存储 → 预览缓存」，不增加主画布常驻操作。点击「检查预览缓存」读取各项目的缓存目录，展示实际可测的文件占用、可清理文件及保留原因；未知目录、符号链接或不可读内容不遍历，明确提示统计不完整。检查不删除文件，也不根据数据库里旧的字节数冒充磁盘占用。

## 明确确认与保留范围

只把已登记的生成代理列为候选：必须核对原素材完整内容、代理内容、创建或迁移记录中的文件身份，以及项目、数据库和路径身份。原片缺失、被替换或无法完整验证时保留代理，以免丢掉可能用于恢复的最后画面。原素材、用户自行放入的文件、未知目录、独立草稿、生成结果暂存和未完成导入不在此清理范围。

检查生成两分钟内有效、只可使用一次的确认。确认只属于发起检查的窗口；新检查、取消、离开存储分类、窗口替换或重新加载使旧确认失效。点击确认后仍重新核对当时列出的每个文件，不自动扩大到后来新增的缓存。单个文件变化或删除失败时保留该项并说明原因，结果按实际已删除文件统计；需要再次检查才能重试。

播放器打开期间即使暂停、暂时没有新的媒体请求，也持有素材使用保护。每次代理媒体响应另有读取保护，直到文件流关闭才释放。排队、编码或发布中的代理全部保留。清理与新的使用保护、代理发布共用项目写入门；项目目录迁移或等待恢复时不执行清理。

只逐个删除核实过的普通代理文件，不递归删除目录，也不删除未知或多硬链接文件。确认快照和最后路径检查覆盖目录替换、同大小内容替换、原素材变动及项目记录变化。操作中取消只停止尚未删除的文件，已经删除的派生缓存不会被说成仍存在。

每个项目的全部原素材引用都会核对路径和文件身份，防止另一条原素材记录以 `cache/./…` 或大小写别名指向候选缓存。即使候选自己的原片完整，只要其他原素材引用缺失或路径不安全，也保守保留该项目的代理。原片恢复后可再次检查。

迁移后的缓存可以凭当前已完成迁移记录证明归属。如果后来的迁移取消或失败替换了这份记录，而原始创建身份也不再匹配，缓存会保留并说明身份无法证明；当前不重新认领这些历史文件。未完成的旧目录清理期间暂停缓存清理，以免删除迁移恢复仍需核对的目标副本。

本版完整校验在项目写入门内串行执行。大文件检查期间，普通保存和新的代理读取可能等待；界面可取消检查。大规模媒体下的检查时长和响应性仍需单独量测，不把存储测试通过当作性能验收。

## 按需重建

删除后保留已有代理登记历史，不改动项目媒体、镜头或裁剪数据，也不增加新的数据库格式。已有代理查询会跳过缺失文件；下一次打开视频编辑页时沿用原流程按需生成。生成不可用时继续使用原片，不伪造缓存成功，也不自动重新接收云端生成结果。

## 验证边界

文件系统、SQLite、使用保护、确认生命周期和重建测试使用临时合成资料，不清理用户项目。隔离 Settings 界面场景位于 `tests/browser/preview-cache-controls.*`；它们验证渲染交互，不替代真实 Electron IPC、媒体播放或正式安装包验收。当前批次的实际执行结果和执行环境限制见 [验收与修复清单](verification-issues.md)。

Windows、macOS 真实播放器暂停期间清理、原生窗口生命周期与目录迁移交错仍应在相应平台验证。历史数据兼容检查不替代这些桌面操作，也不替代签名安装包或历史安装版本升级验证。
