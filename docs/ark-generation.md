# 火山方舟中国区生成

本批将火山方舟接入现有镜头生成组。接口和行为以官方文档及明确的模型能力配置为依据；代码夹具验证、真实服务商调用和 Mac 桌面验收分别记录，不以模拟响应宣称生成可用。

## 配置与确认

区域固定为火山方舟中国区，运行时入口为 `https://ark.cn-beijing.volces.com/api/v3`。在设置中绑定实际开通的 Model ID 或 Endpoint ID 与对应能力版本。本地草稿中的模型名称不是服务商 ID，不自动猜测或预填付费可用模型。更高版本或不同模型能力不能靠改名称假装兼容。

API Key 通过写入式密码输入交给主进程，使用系统安全存储加密；界面只读取是否配置，不取回已有密钥。没有安全存储或 Linux 仅能明文存储时拒绝保存，不把 Key 放进项目包、请求日志或错误信息。打开设置不运行生成请求。

从现有生成组打开准备检查，先保存当前输入，再核对有序文本、参考素材、模型与参数。预览只做本地检查。确认区说明接收方为火山方舟中国区、将发送的文本与参考文件，以及可能发生费用；明确确认后才提交。确认绑定当前窗口与短期预览，重复点击不能重复提交；输入、配置或素材发生变化后需重新检查。

## 参考素材边界

保留现有全能参考交互，不暗中把图片改成首帧／尾帧，也不混用两种模式。图片参考以已核实内容的数据 URL 发送，检查尺寸、比例、数量和整个请求的大小。各模型只接受其已适配的能力范围。

Ark 的视频参考需要可访问 URL 或已登记资产；普通本地视频没有可验证的直接 Base64 映射。当前不猜测上传接口、不新增未经选择的对象存储服务，检查会明确阻止不支持的输入。音频只接受本地能够核对格式、长度及所选能力限制的范围。被服务商拒绝的真实人脸、内容或账号权限以明确错误展示，不承诺所有本地素材均能提交。

## 任务与候选

生成请求在发送前写入独立本机任务记录，并保存不可变的输入快照。修改原组不会改变在途任务。已取得远端任务 ID 的任务可在重开后继续查询；连接中断、超时或无法确定是否已提交时，保留「提交结果未知」，不自动再次发起可能收费的请求。

生成、下载、保存是不同阶段。旧任务本地下载／保存失败后可以明确发起另一轮，但必须重新预览并确认新费用；旧记录和文件保留，正在实际重试或尚在云端运行的任务仍阻止重复提交。结果链接有有效期，完成后尽快接入原有独立暂存与保存队列；下载失败、目录迁移或保存失败不重新生成。完整但未交付的结果继续保留，不能按预览缓存清除。

生成记录提供候选预览，未采用的视频不会自动出现在主画布。已保存候选仍是项目媒体，也可以通过原有项目素材选择器作为参考复用。明确采用图片后加入镜头；采用视频创建新的独立视频卡片及对应镜头上下文，不替换已有组合、裁剪或原片。采用前保存当前编辑，后端核对工作区版本并原子提交，重试不能重复创建。

本地任务记录与 API Key 不随项目包或应用索引备份复制。项目包仍保留已经保存的项目媒体；任务所属镜头或项目无法确认时，保留结果并报错，不按同名项目认领，也不自动清除孤立资料。

## 暂停不等于远端取消

「暂停本地跟踪」只暂停本机查询，不取消远端任务，也不承诺避免费用。Ark 同一个 DELETE 接口会取消排队任务、删除已完成任务记录；先查询排队再删除仍存在任务状态变化的竞态。因此本版不自动调用该接口，远端取消需在官方控制台核对操作，已完成结果仍应尽快保存。
