# 商业可用性推进清单

更新时间：2026-10-04。用户授权持续完善，沿用现有主画布／镜头子画布交互。此清单记录验收差距，不代表已正式发布。

## 当前推进原则

先保证一次完整本地创作能够保存、导出、备份、恢复，再扩大生成与交付范围。账号、计费、ComfyUI、多轨剪辑和协作不自动加入本批；中间切开、重排和画面裁切仍遵守现有暂不实现的约定。云端模型、凭证、费用与正式平台范围需要有明确依据，不能用模拟结果宣称完成。

## 第一批：交付与数据保护

| 能力 | 当前实现 | 尚需验证／完善 |
| --- | --- | --- |
| 退出前保存 | 返回首页、窗口关闭和退出等待草稿；失败留页重试 | Windows 真实桌面；进程崩溃后的未提交文字恢复 |
| 成片导出 | 已保存组合／裁剪输出 MP4、任务进度、取消、失败重试 | 大项目压力、更多真实编码、HDR、安装包内置工具 |
| 项目备份 | 项目包、创建副本、导入独立项目、安全校验 | 大体积百分比进度、跨系统桌面往返、定时备份 |
| 升级保护 | 固定历史提交生成数据并跨进程核对 | 安装器覆盖升级与正式数据格式发布基线 |

## 第二批：编辑容错与素材恢复

镜头素材画布已有独立会话撤销／重做，连续文本与参数输入合并，平移缩放不入栈。项目首页已支持名称搜索与排序。`.afflatus` 首版导出器已固定到 `8b70add2f30f1df960bcc70e0afdd1fb91609109`，旧代码生成项目包、当前代码导入并跨进程重启验证。

素材检查支持打开项目时检查位置、按需完整校验和精确恢复缺失原文件。恢复只接受原内容，不覆盖已有文件或改写项目数据库，恢复后刷新媒体显示而保留画布草稿。详见 [素材恢复边界](media-recovery.md)。

## 继续推进

1. 原保存盘离线后的项目库重连、数据库损坏的可见诊断与独立恢复；不可用项目不能变成空项目。
2. 故障期间仍更新全局保存状态，保留当前草稿并阻止向不可用项目继续写入。
3. 大项目性能、长时间操作、键盘可访问性与更多真实媒体验证，持续保持低常驻按钮密度。
4. 正式桌面交付：决定平台范围，配置打包与媒体工具分发、第三方许可，验证安装与覆盖升级；签名和渠道需真实发布配置。
5. 云端生成：按确认的服务商与凭证接入上传、提交、轮询、取消、失败重试和候选采用，真实调用验证后才宣布可用。任务结果继续经过独立暂存与保存队列。

“商业可用”至少需要核心创作闭环、数据保护、故障反馈、历史兼容、目标平台安装体验与性能验证共同达标。静态构建通过只证明工程可构建，不能替代后面几项。
