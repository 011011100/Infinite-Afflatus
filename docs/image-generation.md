# 图片生成交互

更新时间：2026-10-04。当前实现本地组合、参数与保存，不调用云端、不伪造图片结果。

## 创建与编辑

进入镜头素材子画布，添加文本或导入图片。选中文本／图片后，通过右键菜单或底部「生成图片」组成图片生成组；「生成视频」保留原用途。新组先留在画布，点击「展开编辑」才展开三个悬浮区域，收起返回原组。

- 只有文本（包含文本文件）：文生图。
- 有一张或多张参考图：图生图。模式由实际成员推导，不额外保存可能过时的模式字段。
- 只有参考图：展开时补一个空文本块，供用户描述修改要求；重开不重复添加。
- 左侧复用参考素材轮盘，中间为图片描述文本块，右侧为图片模型、比例和分辨率。
- 移除最后一张参考图后自动显示文生图，文本与参数保持。

文本排序、文本拖出、卡片重命名／缩放、整体移动、解除组合、长按拆出及悬停确认加入均复用既有组件。悬停圆环完成后松手才加入；确认后继续移动取消。不因为创建、合并或加入自动展开编辑。

## 参数与输入限制

| 参数 | 当前可选值 |
| --- | --- |
| 模型 | Seedream 5.0 Lite（默认）、Seedream 4.5 |
| 比例 | 自动适配、1:1（默认）、4:3、3:4、16:9、9:16、3:2、2:3、21:9 |
| 分辨率 | 5.0 Lite：2K／3K／4K；4.5：2K／4K；默认 2K |

从 3K 切换到 4.5 时回到 2K。此处是本地编辑参数，未来接入时需由适配器将比例与分辨率转换成供应商支持的尺寸；不能原样发送自定义字段。当前按生成单张图片设计。

图片组仅接受原生文本、文本文件和图片，参考图片最多 14 张，组内全部素材最多 32 张。图片数按卡片输入数量计算；不默默丢弃重复引用。视频、音频、不可用素材不可组成或悬停加入图片组。同类型组可合并并继承原规则指定的参数；图片组与视频组不直接合并，混选时明确说明原因。

参数依据：[火山方舟图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh&redirect=1)、[Seedream 系列使用说明](https://docs.volcengine.com/docs/ark/seedream-4-0-5-0?lang=zh)。核对日期为 2026-10-04；云端接入时再次核对服务能力、文件限制与模型 ID。本地导入格式仍沿用现有 JPEG、PNG、WebP，不因云端接受其他格式而自动开放。

## 保存与兼容

复用项目 SQLite 的 `generation-workspace`。`GenerationGroup` 新增 `kind: image` 与图片专用参数。视频组允许 `kind: video` 或省略 `kind`；读取旧数据不会补写字段、替换 Seedance 参数或改变旧草稿转换。共享分组逻辑和主进程保存入口都检查图片输入，暂存区中已完整落盘但尚未入库的图片仍可引用。

图片、视频组分别保存参数；拆出／解除组合保留素材及位置，不删除源文件。当前没有图片云端生成服务与结果回填，因此子画布中不会伪造新结果，也不向主画布加入图片节点。未来真实结果仍需经过磁盘暂存与保存队列，进入素材库后才在镜头中引用。

- `tests/image-generation.test.ts`：参数、旧视频字段、同类型合并、混类型拒绝、非法输入、参考图数量、悬停加入、拆出后模式推导、SQLite 重开与暂存引用。
- `tests/browser/image-generation.cjs`：隔离 Electron 中的真实组件与鼠标交互，包括文／图组合入口、展开与收起、参数修改、补空文本和原视频回归。使用合成素材与模拟桌面接口，不操作用户项目。
- `pnpm test:upgrade`：固定历史代码写入的项目由当前代码读取、修改和重启验证；已有基线保留，并为本次新格式追加图片组基线。
- 云端 API 与正式安装包未验证；以上检查不代替真实模型出图或覆盖安装测试。
