# 本地创作交付

更新时间：2026-10-05。

## 视频导出

播放与编辑页右上角提供「导出视频」。导出的是当前单卡片或组合，不按画布位置拼接其他卡片。只有已提交的片段顺序和入出点进入输出；保存中、裁剪手势中或保存失败时不能发起导出。打开导出窗口暂停播放，不增加任何片段播放入口。

用户选择清晰度上限（1080p／720p）与帧率（24／25／30／60），默认 1080p、30 帧。画幅沿用第一段的显示比例，最长边上限分别为 1920／1280，不放大小素材；其他片段等比缩放并填充黑边，不裁掉内容。输出 MP4（H.264、AAC 48kHz 双声道），没有音轨的片段补静音。HDR 素材目前明确拒绝，避免未经色彩映射直接产生错误颜色。

原生保存对话框只选择输出文件，不修改项目位置。已有目的文件、项目库内路径和应用数据目录内路径均拒绝；选择新的文件名即可重试。先把校验完成的临时文件写到目标磁盘，再使用不覆盖已有文件的原子发布。不支持硬链接的磁盘会提示先导出到本机磁盘后再复制，不能以半成品冒充已完成视频。

素材快照在写入闸门内复制到独立 `userData/export-work` 后释放闸门，转码不依赖项目旧路径，所以转码期间允许迁移项目。FFmpeg 分段统一画面与音频格式，最后合并并一次编码 AAC；不改写原片和裁剪数据。导出进度来自 FFmpeg，不使用假进度计时。

同一时间运行一个导出。窗口可收起，在应用顶栏「导出任务」查看进度、取消、定位完成文件或重新导出。任务保留最近 20 项；重试读取当前已保存组合并重新选择输出位置。取消任务或退出应用会终止媒体进程；下次启动将异常中断任务标为失败并提供重试。临时文件只按登记身份清理，不扫描删除用户目录。

返回首页或关闭窗口前，先取消仍在准备中的视频导出，包括等候项目写入、素材复制、哈希校验和媒体探测，让草稿保存能继续。取消覆盖尚未创建任务的请求；离开前打开的原生保存对话框即使稍后返回，也不会重新启动导出。取消准备不会关闭导出服务，保留页面后可以重新导出。已进入编码或最终输出阶段的任务不受这次取消影响：返回首页或仅关闭 macOS 窗口后仍可继续，真正退出应用时才停止。

## 项目包与副本

项目顶栏「项目备份」展示素材数量和预计字节数，提供「创建副本」「导出项目包」。首页「导入项目包」恢复到当前统一项目目录，自动进入新项目。副本与导入始终生成新项目 ID，保留内部镜头、组、文本顺序、参数、标签、画布位置、裁剪与素材引用，不覆盖原项目。

`.afflatus` 是无限画布自己的流式归档格式：版本标识、有上限的 JSON 清单、SQLite 快照和完整素材字节；每个文件带大小与 SHA-256。视频不重复压缩，不承诺显著缩小体积。使用 SQLite backup API 取得包含 WAL 最新提交的一致快照，排除代理缓存、应用设置、凭证与未提交暂存结果。导出前提交界面草稿；尚未落盘的素材引用或缺失素材会阻止导出，提示等待保存或修复。

导入限制路径、文件数量、大小、格式版本与数据库结构，拒绝绝对路径、路径越界、符号链接、不支持的 SQL 对象和清单／数据库不一致。先解包到本次专用临时目录，完整校验后才登记项目；失败只清理本次创建文件。项目包读写受写入闸门保护，目录迁移等待当前操作完成。大项目复制显示处理中并可取消；退出应用会取消未完成操作并等待清理。临时目录和目标旁的部分文件持久登记，异常退出后仅按登记身份回收，离线磁盘恢复后再清理。当前未展示逐字节百分比进度。

项目包不等同于自动历史版本。请定期把完整项目包复制到另一块磁盘。当前尚未实现定时备份、素材重新关联、安装包覆盖升级或云端同步。

## 验证

- 常规测试：项目包真实文件／SQLite 往返、WAL 一致性、旧草稿、未保存引用、恶意路径／数据库、文件篡改、迁移和重新打开；导出选项、拒绝覆盖、取消与恢复。导出准备回归覆盖尚无任务／排队请求取消、大文件哈希未读完即中止并放行草稿保存、取消后重试，以及编码和最终发布继续完成。
- `AFFLATUS_MEDIA_TESTS=1 node --import tsx --test tests/export.test.ts tests/export-media.test.ts`：真实 FFmpeg 合成媒体检查裁剪颜色、顺序、时长、混合尺寸／帧率、静音、采样率、迁移并发及运行中取消。普通 `pnpm test` 明确跳过真实媒体用例，不能将其视为 FFmpeg 验证。
- `pnpm build` 后，macOS 可运行 `pnpm exec electron tests/browser/delivery.cjs`：生产 renderer 文件、真实主进程／preload IPC、窗口关闭前最后一次文本修改、项目包导出导入和真实视频导出。只用隔离临时项目，原生文件选择器由测试返回合成文件路径；不验证用户手动操作系统选择器。
- 历史数据兼容仍运行 `pnpm test:upgrade`，不修改既有历史期望值。

上述验证不包含 Windows 桌面、正式安装包、真实云端 API 或不同硬件长时间大项目压力测试。FFmpeg／FFprobe 仍来自系统或环境变量，安装包内置工具尚未完成。
