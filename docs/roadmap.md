# 实施顺序

更新时间：2026-09-28。

## 0. 工程与文档初始化

当前阶段的交付：

- React + React Flow + Electron + TypeScript 工程和锁定的依赖。
- 能打开的桌面空画布，平移与缩放。
- shadcn/ui + Tailwind CSS 基础，共用按钮、悬浮提示与浅色主题变量。
- 隔离的渲染进程、受限 preload 接口。
- 基础检查、构建命令和 FFmpeg/FFprobe 环境检测。
- 本仓库的产品范围、交互、架构与开发文档。

初始化不包含视频卡片功能。验证结果应记录在提交说明或任务交付中，不提前勾选后续功能。

## 1. 主画布交互原型（下一步）

补充轻量项目首页及新建／打开项目入口：设置中统一配置保存目录，新建时只填项目名，再确认返回首页的交互。同时设计更换保存目录时的迁移范围、空间检查、进度、取消、任务等待保存和旧数据清理反馈。未接入真实持久化时明确标注演示状态，不显示虚假的「已保存」。设计依据见 [本地项目管理](project-management.md)。

优先验证一个完整的短流程：放入两个视频卡片 → 左右吸附 → 变为一张组合卡片 → 点击唯一播放入口 → 从左到右预览 → 返回原画布。

使用少量可公开分发的本地演示视频，不在开始阶段依赖真实云端生成。原型需支持明确的选择、吸附预览、取消、组合拖动和拆分／撤销，再评估多卡片性能。

完成条件：用户能确认主画布操作自然，并通过 `interactions.md` 中相应的验收项。不能只交付一张静态效果图。

## 2. 镜头编辑与裁剪页面

细化并实现镜头编辑视图、放大播放视图、时间截取和画面裁切。验证从主画布进入、选择目标片段、应用／取消、退出后的状态恢复。

模型设置和生成结果可先用明确标注的演示状态承载页面设计。不得把模拟按钮当作真实云端请求或生成成功。

完成条件：用户确认两层工作区的职责清楚；不会为了编辑一个镜头而操作大量节点或窗口；组合播放入口始终唯一。

## 3. 本地项目与真实媒体

本地数据库使用 SQLite。落实统一项目保存目录、自动创建独立项目子目录、修改保存目录时的完整迁移、受管文件登记与旧数据自动清理、按当前项目位置落盘的任务调度、素材管理、自动保存／重新打开、项目包导入导出，再接入 FFprobe、缩略图和必要的代理文件。用原生 FFmpeg 执行裁剪和成片导出。

完成条件：保存后重新打开可恢复素材关系和编辑参数；保存目录迁移或项目包导入后素材仍可用，迁移中断可恢复；按清单清理旧重复数据，不误删用户其他文件，清理失败不回滚新目录；用模拟任务验证下载／回调与迁移交错时的保存位置和重试；真实成片导出顺序、时长、画面裁切和音频符合预览。验证不同分辨率、帧率、编码和带空格／中文的文件路径。

## 4. 云端 AI 生成

选择首批服务商，接入参考素材上传、图片生成、视频生成、状态查询、失败反馈、结果下载和版本采用。

完成条件：经过真实服务商调用验证；生成结果进入对应镜头，主画布仅展示被采用的版本；不会因调整文本而自动触发生成。验证生成中更换保存目录、迁移期间完成、下载中迁移和链接过期恢复，结果按当前路径保存，旧数据清理不丢失任务，迁移不触发重复付费生成。

## 单独规划

登录、计费、账户体系、正式发布、签名和更新不阻塞以上交互设计工作，按需要单独立项。Windows/macOS 的正式支持范围需要确认后安排对应平台验证。
