# 实施顺序

更新时间：2026-10-08。

## 0. 工程与文档初始化

当前阶段的交付：

- React + React Flow + Electron + TypeScript 工程和锁定的依赖。
- 能打开的桌面空画布，平移与缩放。
- shadcn/ui + Tailwind CSS 基础，共用按钮、悬浮提示与浅色主题变量。
- 隔离的渲染进程、受限 preload 接口。
- 基础检查、构建命令和 FFmpeg/FFprobe 环境检测。
- 本仓库的产品范围、交互、架构与开发文档。

初始化阶段不包含视频卡片功能。后续已提前完成本地项目与存储第一版，当前范围见下文，不代表整套视频编辑器完成。

## 已完成：本地项目与存储第一版

- 项目首页、新建／打开／改名，SQLite 保存画布视口和素材登记。
- 统一保存目录、迁移范围预览、空目录与空间检查、进度、取消、按清单清理和中断恢复。
- 独立磁盘暂存、持久化保存队列、迁移等待、切换后按当前路径保存、失败重试。
- 本地视频导入复用该保存链路；后续主画布交互见下文。
- 真实文件／SQLite 和独立进程中断测试；桌面操作验证使用隔离临时目录。

详细实现边界见 [存储实现与验证](storage-implementation.md)。

## 1. 主画布交互原型（第一版已实现）

已实现自由拖动、两端吸附预览与拼接、组合片段选择、拆分、会话内撤销／重做、顺次播放及 SQLite 持久化。保留一个卡片一个播放入口。实现和验证边界见 [画布实现与验证](canvas-implementation.md)。

优先验证一个完整的短流程：放入两个视频卡片 → 左右吸附 → 变为一张组合卡片 → 点击唯一播放入口 → 从左到右预览 → 返回原画布。

使用少量可公开分发的本地演示视频，不在开始阶段依赖真实云端生成。原型需支持明确的选择、吸附预览、取消、组合拖动和拆分／撤销，再评估多卡片性能。

桌面已验证拼接、选择、拆分、撤销／重做、顺次播放与重新打开恢复；实际手感仍需用户体验后调整。触屏、大量素材和无缝音画衔接尚未验证。

## 2. 镜头编辑与裁剪页面

已按最新确认实现全窗口播放与简单时间裁剪：统一轨道、秒数、当前片段、拖动入出点、松手自动保存、撤销／重做。内部图片生成及其他素材制作仍进入子画布。下一步设计镜头素材编辑、画面裁切、中间切开和片段重排。详细边界见 [播放与裁剪实现](sequence-editing.md)。

模型设置和生成结果可先用明确标注的演示状态承载页面设计。不得把模拟按钮当作真实云端请求或生成成功。

完成条件：用户确认两层工作区的职责清楚；不会为了编辑一个镜头而操作大量节点或窗口；组合播放入口始终唯一。

## 3. 本地项目与真实媒体

本地数据库、统一目录、迁移、暂存与保存队列已提前实现。接下来扩展镜头和组合关系、编辑参数持久化、项目包导入导出，再接入 FFprobe、缩略图和必要的代理文件。用原生 FFmpeg 执行裁剪和成片导出。

完成条件：保存后重新打开可恢复素材关系和编辑参数；保存目录迁移或项目包导入后素材仍可用，迁移中断可恢复；按清单清理旧重复数据，不误删用户其他文件，清理失败不回滚新目录；用模拟结果验证迁移期间继续暂存、保存队列等待、切换后提交和崩溃恢复；真实成片导出顺序、时长、画面裁切和音频符合预览。验证不同分辨率、帧率、编码和带空格／中文的文件路径。

## 4. 云端 AI 生成

服务商已确定为火山方舟中国区。已实现图片／视频请求适配、安全配置、明确提交确认、独立任务记录、状态查询、分开下载／保存重试及候选采用的代码；媒体继续走独立暂存与保存队列。图片参考与可验证的 WAV 音频按模型能力发送；本地视频仍缺少经确认的托管 URL／资产上传路线，明确阻止不支持的输入。实际边界见 [方舟生成](ark-generation.md)。

代码／模拟传输验证不代表真实账号调用已完成。先集中完成代码，再按 [Mac 统一验收](mac-acceptance.md) 验证桌面；真实 API、费用和账号能力单独批准。

完成条件：经过真实服务商调用验证；生成结果进入对应镜头，主画布仅展示被采用的版本；不会因调整文本而自动触发生成。验证生成中更换保存目录、迁移期间完成、下载中迁移和链接过期恢复，结果按当前路径保存，旧数据清理不丢失任务，迁移不触发重复付费生成。
