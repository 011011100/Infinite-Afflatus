# 可选随包视频组件

打包链路支持显式提供一份本地 FFmpeg／FFprobe 组件包，默认关闭。程序不会自动下载组件、选择供应商或许可证，也不把文件校验通过当作可以再分发、已签名或编码兼容的证明。

## 组件包约定

构建时使用 `--media-tools <绝对目录>`。目录内必须有 `manifest.json`、两项可执行文件以及至少一份声明的许可／通知文档。清单字段为：`version: 1`；`target` 指定 `platform`（`darwin`／`win32`）和 `arch`（`arm64`／`x64`）；`build` 记录 `version` 和已核实的 `source`；`license` 为与实际构建对应的许可证标识；`tools.ffmpeg` 与 `tools.ffprobe` 各包含包内 `file` 和完整小写 `sha256`；非空 `notices` 数组同样声明每份许可／通知文档的 `file` 与 `sha256`。

目标必须与实际构建完全匹配。路径只能指向包内普通文件，拒绝绝对路径、越界、符号链接、文件名冲突和未声明的额外内容。两项程序和通知文件都按完整 SHA-256 核对；只复制本次清单内的文件，不能顺带收集来源目录中的其他资料。

## 构建与运行

```bash
pnpm package:dir --media-tools /已核实的组件包目录
pnpm package:local --media-tools /已核实的组件包目录
```

组件先复制到本次拥有的独立暂存目录，再作为 `Resources/media-tools` 放在 ASAR 之外。构建完再次验证实际包内文件与原清单；ASAR 文件白名单和禁止不受控 unpacked 依赖的规则保持。可用 `--output <新的绝对目录>` 隔离一次验收的产物；显式目录已经存在则拒绝，不清空已有目录。

运行时优先级为：环境变量 → 用户保存的明确路径 → 经过校验的随包组件 → 既有 PATH／Homebrew 查找。明确环境变量或保存路径失效时不静默换程序。没有附带组件目录时保持旧行为；附带目录损坏时明确阻止受影响的任务，用户仍可显式选择其他本机工具，本地项目与原片预览不因此无法打开。

只在正式应用包上下文注入资源目录，不扫描项目目录或开发 Electron 的其他资源。设置显示「随应用附带」及实际路径；读取设置不启动程序。诊断与真实任务共用同一解析结果，任务开始后固定所用工具；文件身份或内容变化后不能沿用旧的校验结果。

每个已固定的随包工具对象在主进程持有不可通过 IPC 复制的原始校验证据。即使输入复制、探测等异步准备已经完成，每次真正启动组件前仍核对原清单与完整文件／目录身份及哈希。替换程序、连同清单一起更换、复制或伪造工具位置对象均不能继承原启动授权；不会暗中切换到新组件。

## 当前交付边界

这批完成的是校验、解析、打包及拒绝异常文件的代码和测试。没有下载或提交真实二进制，没有确定发行商、编解码构建选项、许可义务或签名方案。测试中的惰性字节／模拟版本程序只证明文件契约和调用路径，不证明真实 FFmpeg 编码。

正式随包分发仍需提供可信的目标架构构建与完整许可材料，并分别验证编码、系统加载、安装升级和签名／公证。统一 Mac 测试入口见 [Mac 统一验收](mac-acceptance.md)。
