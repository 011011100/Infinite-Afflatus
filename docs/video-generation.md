# 视频生成工作台

当前阶段先实现页面与本地草稿，不发起云端请求、不产生费用，也不伪造生成结果。

## 页面与交互

- 项目顶栏「生成视频」打开全窗口工作台。返回时保留主画布的位置和选择；双击已有视频仍进入播放与裁剪。
- 左侧一列悬浮素材卡片，独立滚动。可从本地上传图片、视频、音频和文本，也可选择项目已有素材。图片直接预览，视频／音频可播放，文本可展开阅读或插入正文。移除卡片仅解除草稿引用，素材保留在项目内，可重新选择。
- 中间是提示词编辑区。插入文本使用当前光标／选区，不自动替换已有正文。最多 10,000 个字符是本地编辑上限，不代表云端模型输入额度。
- 右侧先按 Seedance 2.0 全能参考设计，含标准版／Fast、画面比例、分辨率、时长、生成声音。Fast 下禁用 1080p；从标准版切换时自动回到 720p。时长支持 4–15 秒整数和智能选择。
- 暂未接入生成服务，生成按钮明确禁用；API 鉴权、素材上传、模型素材时长／数量／格式校验、任务提交与结果回填留待接入阶段。文本文件是创作资料，使用时插入正文，不作为独立多模态文件发送。

当前参数参考：[火山方舟创建视频生成任务 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh&redirect=1)、[Seedance 2.0 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh&redirect=1)。当前只提供常用参数子集，实际接入时按所选服务的实时能力再次校验。

## 保存边界

每个项目目前保存一份工作草稿（提示词、素材引用、参数），写入项目 SQLite 的可选 `generation-draft` 元数据。兼容已有项目，不改变数据库版本。停止编辑 500 ms 后串行保存；慢响应不能覆盖后续输入。返回画布前等待保存完成，失败保留页面并提供重试。迁移期间暂停草稿写入，迁移解除后重试。

导入素材复用「磁盘暂存 → 保存队列」流程，使用稳定素材 ID 引用，不保存用户原始文件绝对路径。新增音频／文本目录，迁移仍只处理已注册清单。专用于生成的参考视频标记 `usage: reference`，不自动在主画布创建节点；选择画布已有视频作参考不会改变原卡片。

本地支持 JPEG、PNG、WebP；MP4、MOV、WebM、M4V；MP3、WAV、M4A、OGG；UTF-8 TXT／Markdown（最多 1 MB）。这些是本地管理与预览格式，未来提交前需按模型要求转换或限制。素材缺失、预览失败、批量导入部分失败都显示可恢复提示。

尚未实现每个镜头独立草稿、参考图子画布、首尾帧角色分配、候选结果历史。页面先供交互确认，后续围绕镜头引用演进。

## 本轮验证

- `pnpm test`：114 项通过；新增覆盖草稿默认值、版本冲突、跨项目素材拒绝、四类素材保存与迁移、迁移期间暂存、文本编码与大小限制。
- `pnpm check`、`pnpm build` 通过。
- 浏览器使用真实 React 组件和模拟桌面接口，验证三栏布局、文本插入、项目素材选择与重新添加、Fast 分辨率联动、重新打开恢复草稿；模拟 800 ms 保存延迟及保存失败，验证新输入保留、离开前保存和重试。
- Electron 开发进程已启动。桌面自动控制在主进程热更新后连接失效，因此本轮没有完成桌面文件选择、四类真实媒体预览的完整验收；浏览器验证不替代此项。
- 云端 API 与正式安装包未测试。
