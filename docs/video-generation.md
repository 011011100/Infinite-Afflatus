# 镜头素材子画布

当前阶段实现画布交互与本地草稿。云端提交按钮明确禁用，尚未接入生成服务，不伪造生成结果。

## 入口与组合

- 主画布继续只放视频与待生成镜头。点「新建镜头」打开空的镜头素材子画布；已有视频点「编辑镜头素材」，组合视频需先选中具体片段。双击已有视频仍然打开播放与裁剪页。
- 子画布是可平移、缩放的空间。文本、图片、视频、音频作为独立卡片自由排列，不使用三栏表单。拖动卡片标题移动；文本正文直接编辑，媒体区域用于预览。
- 左键拖动空白区域平移画布，右键拖动框选；框选松手保留选择，再右键单击打开菜单，通过「生成视频」将选中的独立素材组成生成组。选中后也提供底部按钮作为同一操作入口。Windows 用 Ctrl、macOS 用 ⌘ 加选；保留空格拖动和中键平移。框选时按 Esc 或窗口失焦会取消操作并恢复原选择。
- 框选「组＋卡片」或「组＋组」后，通过「合并成组」建立一个新组。选中的组包含全部成员，父组与成员同时选中只计一次；单独选中的组内卡片可以移入新组，未选中的同组卡片留在原组。合并不嵌套分组，也不复制素材。最终只保留一套参数：优先沿用所选组中当前展开的参数，没有展开时沿用最左侧组的参数。32 张上限按展开后的素材数计算，超出时禁用合并。
- 多选完成后，至少两个独立选中对象的外侧保留蓝色虚线框，跟随卡片位置和画布视口；清除选择后移除。外框不拦截点击、编辑或拖动，正式生成组及其成员同时被选中时不重复叠框。
- 画布上的组保留蓝色实线外框。成组后或点击「展开编辑」，组合从原位置展开为三个悬浮区域，收起时返回原组。左侧为图片／视频／音频的弧形轮盘，中间为多文本块组成的大卡片，右侧为 Seedance 参数。原画布仅轻微压暗／模糊，不跳转新页面，不用整块矩形底板包裹三个区域。组仍可整体移动或解除，解除后保留绝对位置；每组最多 32 张卡片，这是画布限制，不代表模型额度。
- 素材轮盘突出当前卡片，上下卡片缩小、旋转退后。滚轮或上下按钮切换，弹簧从当前位置和速度接续，快速反向也无需等待上一段过渡完成；媒体保留预览控件。
- 中间每个文本块独立保存内容和顺序，用轻分隔线区分。原生文本与文本文件都放在这里，编辑文件保存可选 `textOverride`，不改写源文件。无文本时补空块，重复打开不重复添加；已达 32 张上限时先移出素材。
- 文本块标题长按 700 ms 后拿起，拖动时跟随指针；组内松手重排，拖出中间卡片之外 20 px 后提示「松手移回画布」，松手只移出该块。提前移动、原地长按后松手、Esc、指针取消、窗口失焦／尺寸变化均不提交。正文编辑与按钮操作不触发长按。长列表支持边缘自动滚动，另有上移／下移／移回画布按钮与手柄方向键。悬浮编辑的长按拿起与画布的长按拆出分别处理。
- 长按组内卡片标题或非交互区域 700 ms，蓝色圆环完成后松手，只拆出该卡片。移动超过 5 px、Esc、滚动、取消或窗口失焦均取消拆出；文字输入、播放控件、按钮及带修饰键的加选不触发。复用设置里的长按拆分开关，并可通过右键「拆出卡片」完成相同操作。剩余卡片的位置与原组参数不变，最后一张拆出后移除空组框。拆出的卡片放在组外空位，必要时调整视野使其可见。
- 生成参数沿用 Seedance 2.0 标准版／Fast、比例、分辨率、4–15 秒整数／智能时长、声音开关。Fast 下禁用 1080p；从标准版切换时自动回到 720p。

模型参数参考：[火山方舟创建视频生成任务 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh&redirect=1)、[Seedance 2.0 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh&redirect=1)。实际接入时需再次确认所选服务的实时能力。

## 保存与素材

项目 SQLite 的可选 `generation-workspace` 元数据保存镜头列表，每个镜头包含主画布位置、子画布视口、素材节点与生成组参数。已有视频通过稳定素材 ID 关联镜头，主画布拼接与拆分不影响此关系。旧的项目级 `generation-draft` 在读取时转换为镜头、文本／参考卡片与生成组，保留原参数；首次编辑后保存新结构。

文本块顺序使用节点数组中的组内顺序；重排只替换这些成员的位置，不影响媒体和其他组合。拆出、合并与重开保留节点 ID、内容和文件引用。停止编辑 350 ms 后串行保存。保存响应只更新版本号，不覆盖新输入；返回主画布前等待保存，失败时保留子画布并可重试。版本冲突拒绝覆盖。目录迁移期间暂停写入，解除后继续保存。生成组与普通视频组合使用不同数据结构。

导入素材复用「磁盘暂存 → 保存队列」，以稳定 ID 引用。参考视频标记 `usage: reference`，不自动出现在主画布；选择已有视频作参考不改变视频卡片。移除卡片只移除引用，不删除文件。本地支持 JPEG、PNG、WebP；MP4、MOV、WebM、M4V；MP3、WAV、M4A、OGG；UTF-8 TXT／Markdown（最多 1 MB）。文本卡片最多 10000 字符。
