# 播放与简单时间裁剪

更新时间：2026-09-30。

## 已实现

卡片唯一播放入口与双击均进入占满应用窗口的编辑页；不使用预览弹窗，也不强制切换系统全屏。主画布保留挂载并暂时不可交互，返回后恢复原位置、选择和焦点。

- 上方画面，下方统一播放／暂停、静音、组合时间、当前片段。
- 一条按有效时长比例排列的时间轨道，有秒数刻度、缩略图和播放指针；可以横向滚动、缩放和跨片段定位。轨道卡片不叠加文件名、编号和文字底部遮罩，片段名保留在无障碍标签中。
- 不再单独展示选中片段的名称、入出点与保留时长栏。「恢复原片」位于轨道工具栏右侧、缩放按钮左边，仅恢复选中的片段。缩放使用减号／百分比／加号，范围为 50%–600%，每次调整 25 个百分点；拖动裁剪手柄期间禁用缩放。
- 选中片段后拖动两侧手柄设置入点与出点，拖动即时预览边界，松手保存一次。入点手柄移动左边缘并固定右边缘，出点手柄移动右边缘并固定左边缘；相邻片段随对应一侧移动，仍连续播放。轨道比例只随主动缩放或窗口尺寸变化，松手保存不重新缩放或跳位。Esc、窗口失焦、窗口缩放或取消指针会放弃草稿。
- 手柄方向键微调 0.1 秒，Shift + 方向键调整 1 秒；范围约束到源视频，至少保留 0.1 秒（不足 0.1 秒的源片保留整段）。可以向外拖回或「恢复原片」。
- 缩略图以源素材起点为基准绘制，入点变化时按源时间偏移裁去左侧画面，不从新的左边缘重新铺图。两端拖柄为卡片内部的细长白色圆角竖条，不再突出蓝色块；透明命中区向外保留 8 像素容差、向内最多到片段中点，极短片段也不重叠。编辑期间保留轨道曾达到的最大滚动范围，裁短后不自动回滚；重新进入编辑页再按当前范围布局。
- 撤销／重做使用画布共用会话历史、最多 50 步；编辑页仅处理当前组合的裁剪，不跨入之前的画布结构操作。快捷键沿用设置并区分 macOS／Windows。
- 每次松手进入串行保存队列，通过原有项目 IPC／迁移闸门保存 SQLite；保存期间手柄仍可继续操作，较早的保存回执不会覆盖新的拖动。失败放弃依赖该次保存的后续草稿，恢复最后已保存范围并提示。迁移时允许播放，禁止编辑。返回画布后卡片时长同步裁剪长度。

## 数据与模块

`CanvasCard.trims` 是可选的 `assetId -> { start, end }`，单位为源视频的秒数。未提供表示完整源片。沿用画布 version 1 和 SQLite 容器格式，旧项目自然兼容；主进程验证有限数值、非负入点、出点大于入点、素材归属，并将裁剪纳入过期写入比较。渲染进程获取媒体时长后再约束到真实范围。

- `shared/canvas/trim.ts`：入出点与范围约束；`model.ts`：格式和过期写入校验；`operations.ts`：拼接合并裁剪映射、拆分分配给对应连续组。
- `editor/sequence-editor.tsx`：页面与共用按钮；`use-sequence-editor.ts`：草稿、选中片段、保存和快捷键。
- `editor/trim-save-queue.ts`：连续裁剪的乐观状态、顺序提交和失败恢复；`use-trim-gesture.ts`：稳定的指针捕获、拖动基准和取消。
- `editor/sequence-timeline.tsx`：刻度、定位与手柄展示；`filmstrip.tsx`：复用静态首帧绘制轨道缩略图；`timeline.ts`：组合时间与源时间换算。
- `editor/timeline-toolbar.tsx`：轨道统计、恢复原片与缩放按钮。
- `editor/trim-handle.tsx`：内置拖柄、命中区域与键盘微调。
- `editor/use-sequence-frames.ts`：复用项目缩略图缓存读取时长，限制新解码并发。
- `playback/sequence-playback.ts`：双缓冲、播放时钟、出点切换、暂停和取消；`seek-video.ts`：可取消的解码定位；`use-sequence-playback.ts`：React 生命周期。修改裁剪范围不重建播放器。

源文件不重写，当前没有导出新视频。轨道图片是源片首帧重复展示，不是多位置采样的影片缩略图。边界控制是浏览器预览精度，尚不承诺逐帧编辑、音频无缝或导出精度。中间切开、片段重排、画面裁切、FFmpeg 导出本轮未实现。
