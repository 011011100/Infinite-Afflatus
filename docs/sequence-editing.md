# 播放与简单时间裁剪

更新时间：2026-09-28。

## 已实现

卡片唯一播放入口与双击均进入占满应用窗口的编辑页；不使用预览弹窗，也不强制切换系统全屏。主画布保留挂载并暂时不可交互，返回后恢复原位置、选择和焦点。

- 上方画面，下方统一播放／暂停、静音、组合时间、当前片段。
- 一条按有效时长比例排列的时间轨道，有秒数刻度、缩略图、片段名和播放指针；可以横向滚动、缩放和跨片段定位。
- 选中片段后拖动两侧手柄设置入点与出点，拖动即时预览边界，松手保存一次。拖动时固定比例，松手后收拢。Esc、窗口失焦或取消指针会放弃草稿。
- 手柄方向键微调 0.1 秒，Shift + 方向键调整 1 秒；范围约束到源视频，至少保留 0.1 秒（不足 0.1 秒的源片保留整段）。可以向外拖回或「恢复原片」。
- 撤销／重做使用画布共用会话历史、最多 50 步；编辑页仅处理当前组合的裁剪，不跨入之前的画布结构操作。快捷键沿用设置并区分 macOS／Windows。
- 松手后通过原有项目 IPC／迁移闸门保存 SQLite；失败恢复已保存范围并提示。迁移时允许播放，禁止编辑。返回画布后卡片时长同步裁剪长度。

## 数据与模块

`CanvasCard.trims` 是可选的 `assetId -> { start, end }`，单位为源视频的秒数。未提供表示完整源片。沿用画布 version 1 和 SQLite 容器格式，旧项目自然兼容；主进程验证有限数值、非负入点、出点大于入点、素材归属，并将裁剪纳入过期写入比较。渲染进程获取媒体时长后再约束到真实范围。

- `shared/canvas/trim.ts`：入出点与范围约束；`model.ts`：格式和过期写入校验；`operations.ts`：拼接合并裁剪映射、拆分分配给对应连续组。
- `editor/sequence-editor.tsx`：页面与共用按钮；`use-sequence-editor.ts`：草稿、选中片段、保存和快捷键。
- `editor/sequence-timeline.tsx`：刻度、定位与手柄交互；`filmstrip.tsx`：复用静态首帧绘制轨道缩略图；`timeline.ts`：组合时间与源时间换算。
- `editor/use-sequence-frames.ts`：复用项目缩略图缓存读取时长，限制新解码并发。
- `playback/sequence-playback.ts`：双缓冲、播放时钟、出点切换、暂停和取消；`seek-video.ts`：可取消的解码定位；`use-sequence-playback.ts`：React 生命周期。修改裁剪范围不重建播放器。

源文件不重写，当前没有导出新视频。轨道图片是源片首帧重复展示，不是多位置采样的影片缩略图。边界控制是浏览器预览精度，尚不承诺逐帧编辑、音频无缝或导出精度。中间切开、片段重排、画面裁切、FFmpeg 导出本轮未实现。

## 验证

- 自动测试覆盖有效时长和边界换算、手柄范围、裁剪随拼接／拆分保留、过期与非法写入、SQLite 重新打开、撤销与源文件不变；播放器覆盖入点预加载、出点切换、末段停止、回到开头播放、暂停与异步定位取消。
- 浏览器组件实测使用真实蓝／绿／橙样例视频与模拟保存：拖动出点、键盘修改入点与出点、总时长同步、撤销／重做、关闭释放媒体、重新打开恢复参数，以及模拟保存失败后恢复旧范围并提示。
- macOS Electron 实测：从首页打开项目进入全窗口编辑页，蓝色片段从 0–4 秒改为 1–3 秒，组合从 13 秒变为 11 秒；⌘ Z／⌘ Shift Z 可在手柄聚焦时撤销／重做；返回画布显示 2 秒，回首页重开后仍为 11 秒。使用独立示例项目库，不修改个人项目。
- 大量媒体、触屏、Windows 桌面、真实音轨无缝衔接和正式安装包待验证。
