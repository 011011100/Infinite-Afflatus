# 本地项目与存储实现

更新：2026-09-28。本文区分当前实现与产品文档中的后续设计。

## 已可操作的流程

项目首页只输入名称即可创建项目。默认根目录为系统文稿目录下的 `Infinite Afflatus/Projects`，每个项目使用 UUID 子目录。项目名称不参与路径，允许同名；项目内的 `project.sqlite` 保存名称、画布视口和素材登记，素材存相对路径。

首页可重新打开项目，画布顶部可改名。导入视频经由原生文件选择器，复制到项目，不改动导入源文件。画布按导入顺序排布视频，每张卡片只有一个播放按钮，点击打开独立播放器。当前尚未实现卡片拖动、拼接、时间裁剪、画面裁切、镜头编辑及项目包导入导出。

「保存与存储」显示统一根目录，支持打开文件夹、更换目录、迁移范围预览、进度、取消和旧副本清理重试。本版目标目录需要为空，且不能与原目录、应用数据目录相互包含。已有内容的项目目录导入属于后续项目包功能，不通过迁移入口接管。

## 文件与模块

| 模块 | 职责 |
| --- | --- |
| `main/projects` | 独立项目数据库、创建／打开／更新、重建项目索引 |
| `main/saving/staging.ts` | 接收结果流，写入固定磁盘暂存区，校验、容量限制、重启恢复 |
| `main/saving/save-queue.ts` | 按当前项目根目录保存，幂等登记素材，失败保留结果并允许重试 |
| `main/migration` | 复制清单、校验、原子切换、按文件清理、中断恢复 |
| `main/storage` | SQLite 封装、文件工具、写入屏障与服务组合 |
| `main/desktop` | 窗口、类型化 IPC、ID 到受管媒体文件的解析 |
| `renderer/src/features` | 项目首页、设置、保存状态、画布及播放视图 |

Electron 主进程负责本地服务，不另开 HTTP 后端。使用 Node 内置 `node:sqlite`；短数据库操作同步执行，文件读写与哈希异步执行。项目连接按操作打开、关闭，采用 DELETE journal，迁移前等待所有已获准写入完成；不存在直接复制一个仍在写入的项目数据库的流程。

应用 `userData/app.sqlite` 保存根目录、项目索引、保存任务和迁移日志，`userData/staging` 保存独立的结果文件。两者始终位于项目根目录之外。格式版本不匹配的项目拒绝打开。

## 生成与保存边界

后续云端适配器将结果标识和字节流交给 `Library.acceptResult`，不持有项目绝对路径。本版用本地视频导入和测试数据验证这条链路，未接入真实生成、云端任务轮询或结果重新下载。

1. 保存任务先写入应用 SQLite，状态为 `receiving`；文件写入 `.part`。
2. 写入完成并刷盘后登记大小和 SHA-256，再转成 `.ready`、标记 `ready`。
3. 队列取得共享写入许可后才读取当前项目根目录，复制文件并校验，然后登记项目素材。
4. 项目文件与数据库都成功后才标记任务 `saved`，再清除对应的完整暂存文件。

同一个项目／结果标识去重。保存中断可重试而不重新生成；在项目数据库成功、应用队列尚未确认之间崩溃，重启会识别已经落盘的素材，避免重复记录。接收中断且文件不完整会显示失败，等待重新导入或后续服务商下载恢复；不会把部分文件当作成功结果。

暂存容量当前上限为 20 GiB，按实际磁盘文件计算；另检查可用空间并预留 16 MiB。达到容量限制会停止当前接收并显示失败，不淘汰尚未保存的完整结果。尚无暂存管理界面或自动恢复远端下载。

素材优先使用同盘临时文件和硬链接发布；不支持硬链接的文件系统使用排他复制。未完成且未登记的副本不会覆盖现有文件，重试使用新的文件名。异常退出可能保留部分临时文件；它们不进入素材登记或自动递归清理。

## 迁移与清理

迁移先关闭新的项目写入许可，等待已进入的写入结束。此时接收结果仍可继续进入固定暂存区，队列等待。正式清单包括每个已登记项目的数据库与素材，不扫描整棵目录来扩大删除范围；可重新生成的 cache 目前无受管文件。

复制后核对源文件身份、大小、时间及 SHA-256，并校验目标文件；随后在应用数据库的同一事务中更新根目录和迁移日志方向。素材路径为相对路径，不需要逐个重写数据库。

旧副本清理只处理具有复制回执的文件，再次核对身份、内容和所属目录。目标项目也必须仍有对应素材记录与文件。源文件被修改或替换则保留并提示；未登记的用户文件完全不参与清理。只删除仍属于原清单且已空的子目录，永不递归删除用户选择的根目录。

- 切换前取消或崩溃：继续使用旧根目录，清理能够证明属于本次复制的目标副本；无回执或无法确认身份的残留保留。
- 切换后崩溃：使用新根目录，恢复旧副本清理，待保存结果从新位置提交。
- 清理失败：新目录保持有效，结果可正常保存，设置页提供清理重试；未处理完前不开始第二次迁移。

应用使用 Electron 单实例锁和进程内写入屏障。当前不支持多个独立应用配置或其他电脑同时写入同一项目库；不能把本机测试当作网络盘并发与断电可靠性认证。保存目录失联时显示错误，不悄悄创建替代项目库。

## 验证边界

集成测试覆盖真实 SQLite 与临时文件：项目持久化、同名项目、结果幂等、迁移期间暂存、在途写入屏障、只清理登记文件、保留用户文件与替换文件、符号链接防护、失败重试、容量限制、较新格式拒绝、索引重建。

独立子进程在切换前和切换后直接退出，再由新实例验证迁移日志、暂存和队列恢复。桌面验证在独立临时目录完成了创建项目、视频导入、单入口放大播放、修改保存目录和保留无关文件。

这些验证不包含真实云端 API、FFmpeg 编辑与导出、跨物理磁盘故障、Windows 安装包、网络盘或大规模素材性能。
