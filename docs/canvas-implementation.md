# 主画布交互第一版

更新时间：2026-09-28。

## 可操作的流程

导入本地视频 → 拖动视频卡片 → 靠近另一张卡片的左／右边缘 → 查看顺序提示 → 松开形成一个组合 → 点击组合唯一的播放入口 → 在大浮层中按序预览 → 关闭后回到原画布。

- 单击片段只选中该片段；点击空白取消选择。画布中的视频不自动播放。
- 两端追加支持单卡片与组合、组合与组合，保留各自内部顺序。
- 吸附容差按屏幕像素计算，不随画布缩放变得难以操作。拖动不足 5 像素按点击处理，不误拼接。
- 拖动时显示目标边缘和将形成的播放顺序；移开取消提示，Esc 恢复拖动前的位置。松开后才写入。
- 组合仍是一个 React Flow 节点，可以整体移动。最多显示四段宽度，更多片段在卡片内横向滚动。
- 选中组合后底部出现「拆分组合」，按原顺序横向排开。当前没有中间插入、内部排序、复制或删除素材。
- 撤销／重做支持本次打开项目期间的移动、合并、拆分，最多保留 50 步。支持按钮和 Cmd/Ctrl Z、Cmd/Ctrl Shift Z；输入框和浮层不触发画布快捷键。重新打开项目后历史清空，画布结果保留。
- 大浮层使用单个原生视频播放器，播放完后切到下一段，可点击片段名称跳转。切换片段可能有间隔，不承诺无缝播放。当前进度条是当前片段的进度。

| 页面 | 内容 | 本轮状态 |
| --- | --- | --- |
| 主画布 | 视频卡片排列、组合、整体预览 | 第一版已实现 |
| 当前视频大浮层 | 当前视频预览、裁剪、镜头设置与素材入口 | 预览已实现；编辑与裁剪待实现 |
| 素材子画布 | 内部图片生成、其他素材制作及候选内容 | 已确定形式；待设计实现 |

素材子画布不是主画布中不断展开的新节点。进入／返回需保留来源镜头、主画布视口和选择状态。云端模型和生成任务尚未接入。

## 数据与文件分工

- `src/shared/canvas/model.ts`：卡片数据、格式校验、旧项目兼容及局部更新约束。
- `src/shared/canvas/operations.ts`：左右吸附、拼接、拆分及反向操作。
- `src/main/projects/project-database.ts`：在项目 SQLite 事务内验证并保存画布。
- `src/main/projects/project-service.ts`：通过迁移写入闸门访问当前目录，更新项目索引。
- `src/renderer/src/features/workspace/use-canvas-document.ts`：保存状态与撤销历史；失败回读项目并提示。
- `use-card-drag.ts`：拖动过程、吸附预览和取消，移动过程中不写磁盘。
- `project-canvas.tsx`：React Flow 视图组合与选择；保留节点测量尺寸，避免选中时短暂隐藏造成点击丢失。
- `video-card.tsx`、`canvas-actions.tsx`、`sequence-player.tsx`：卡片、工具条与浮层播放器。

项目数据库 `metadata.canvas` 存储 `{ version: 1, revision, cards }`。每个卡片分别持有 `position` 和有序 `assetIds`，播放顺序不依赖横坐标。本期每个视频素材在画布中出现一次；以后镜头版本管理会引入独立镜头／片段实体，不能把当前素材 ID 模型直接当作完整剪辑模型。

沿用数据库容器格式 1，画布使用独立版本。旧项目缺少 `canvas` 时，在读取时生成确定的初始排布，不修改原文件；首次操作才写入该键。读取到新视频时在已有卡片下方补入，不改变既有组合。

界面发送受影响卡片的 `before/after`，主进程先比较原状态、检查素材集合完全相同，再原子替换受影响卡片。后到的导入不会被旧画布整份覆盖。过期操作、重复素材、标识冲突、非有限坐标均拒绝；迁移期间拒绝新画布写入，迁移完成后按当前保存目录提交。

## 验证记录与边界

- 26 项测试通过，包括原有 17 项存储测试，以及 9 项新增画布测试：左右组合顺序、缩放吸附容差、拆分／反向操作、非法及过期更新、旧项目只读兼容、重开恢复、并发导入保留、迁移闸门与新目录写入。
- `pnpm check`、`pnpm build` 通过。
- macOS Electron 桌面实测：左侧和右侧拼接、一个组合一个播放入口、单击片段选中不播放、整体移动、拆分、键盘撤销／重做、蓝色片段自动切换到绿色片段、Esc 关闭预览、回项目列表后重开保持坐标与组合。
- 使用独立临时项目库和 FFmpeg 生成的蓝／绿／橙色视频；没有修改个人项目库、调用云端生成或上传媒体。
- 按住鼠标时的 Esc、触屏／跨平台、大量媒体、超长组合、真实音轨衔接、裁剪、FFmpeg 导出和正式安装包仍需后续验证。
