# 主画布交互第一版

更新时间：2026-09-28。

## 可操作的流程

导入本地视频 → 拖动视频卡片 → 靠近另一张卡片的左／右边缘 → 查看顺序提示 → 松开形成一个组合 → 点击组合唯一的播放入口 → 在大浮层中按序预览 → 关闭后回到原画布。

- 共用弹窗接入 transitions-dev 的缩放／淡入淡出，鼠标打开 250 毫秒、关闭 150 毫秒；快捷键和减少动态效果模式即时响应。关闭时立即暂停媒体，退场动画不会延长播放。圆环完成图标使用同一套图标切换动效。
- 画布顶部移除常驻操作说明，保留拼接预览与保存状态。
- 长按反馈使用片段中央的圆环进度及完成勾选图标，不覆盖底部文字横条；选中下划线持续保留。
- 圆环采用缩放与透明度过渡，淡入 220 毫秒、淡出 160 毫秒；独立反馈层保留退出动画，拆分不等待动画，原卡片卸载也不会中断退场。
- 缩略图按项目／素材／内容哈希缓存已解码的静态画面和时长。合并、拆分及撤销后的新卡片在首次绘制前复用缓存，不重新挂载视频解码器；关闭项目时释放缓存并取消未完成的解码。读取失败显示占位图标，不影响打开原片播放。
- 合并与局部拆分使用 GSAP Flip 驱动真实缩略图的位置、宽度与圆角，SVG 绘制卡片表面及底部液态连接，440 毫秒收拢或分离；撤销／重做复用同一流程。过渡可中断，减少动态效果模式直接呈现最终结果，保存失败不播放成功过渡。
- 双击卡片打开播放浮层；长按组内片段 0.7 秒后松开执行局部拆分，移动、提前松开、Esc 和窗口失焦取消。
- 设置中可开关长按拆分，自定义播放、拆分、撤销、重做快捷键，并恢复默认；配置保存在应用 SQLite，独立于项目目录。
- 单击片段只选中该片段；点击空白取消选择。画布中的视频不自动播放。
- 两端追加支持单卡片与组合、组合与组合，保留各自内部顺序。
- 吸附容差按屏幕像素计算，不随画布缩放变得难以操作。拖动不足 5 像素按点击处理，不误拼接。
- 拖动时显示目标边缘和将形成的播放顺序；移开取消提示，Esc 恢复拖动前的位置。松开后才写入。
- 组合仍是一个 React Flow 节点，可以整体移动。最多显示四段宽度，更多片段在卡片内横向滚动。
- 选中组合内的具体片段后，底部出现「拆分选中片段」。该片段独立，前后两侧分别保留连续组合，不跨段自动拼接；没有选中片段时不显示拆分入口。各部分按原顺序从左到右排列，间隔 48 个画布像素，最左部分保留原标识和位置；只有一段的部分自然成为单卡片。当前没有中间插入、内部排序、复制或删除素材。
- 撤销／重做支持本次打开项目期间的移动、合并、拆分，最多保留 50 步。支持按钮和可自定义快捷键（默认 Cmd/Ctrl Z、Cmd/Ctrl Shift Z）；输入框和浮层不触发画布快捷键。重新打开项目后历史清空，画布结果保留。
- 大浮层复用两个原生视频播放器，只显示当前片段并预加载下一段。切换前保留原画面，等新片段首帧可用再切换；快速连点只采用最后一次选择。加载失败保留原画面，可重试或跳到其他片段。音量、静音和倍速沿用，预加载播放器暂停且静音，关闭浮层时立即取消待播放请求并在卸载时释放媒体。预览区尺寸固定，横／竖视频使用等比包含；全屏作用于整个播放区域，避免切换视频退出全屏。当前进度条仍是当前片段的进度，不承诺音频无缝衔接，暂不提供只播放单个底层元素的画中画。

## 页面分工（用户已确认）

| 页面 | 内容 | 本轮状态 |
| --- | --- | --- |
| 主画布 | 视频卡片排列、组合、整体预览 | 第一版已实现 |
| 当前视频大浮层 | 当前视频预览、裁剪、镜头设置与素材入口 | 预览已实现；编辑与裁剪待实现 |
| 素材子画布 | 内部图片生成、其他素材制作及候选内容 | 已确定形式；待设计实现 |

素材子画布不是主画布中不断展开的新节点。进入／返回需保留来源镜头、主画布视口和选择状态。云端模型和生成任务尚未接入。

## 数据与文件分工

- `src/shared/canvas/model.ts`：卡片数据、格式校验、旧项目兼容及局部更新约束。
- `styles/motion.css`、`components/ui/use-modal-motion.ts`、`lib/input-method.ts`：共用动效、弹窗退场清理与键盘即时响应。
- `src/shared/interaction/`、`src/main/settings/interaction-settings.ts`：手势判定、快捷键格式与校验、应用级设置存储。
- `features/settings/`：设置分类、交互选项、快捷键录入与存储迁移。
- `use-long-press-split.ts`、`use-canvas-shortcuts.ts`、`video-thumbnail.tsx`：可取消长按、画布快捷键与缩略图反馈。
- `hold-feedback.tsx`、`hold-split-indicator.tsx`、`styles/hold-feedback.css`：独立的长按反馈层、进度与可中断的缩放／淡入淡出。
- `thumbnail-cache.ts`、`decode-thumbnail.ts`、`thumbnail-provider.tsx`：缓存生命周期、首帧解码和画布内共享，渲染进程不读写文件、不导出像素、不放宽媒体协议权限。
- `motion/use-card-morph.ts`：保存前采集与保存后 DOM 就绪衔接、中断及卸载清理；`motion/snapshot.ts`：屏幕到画布坐标换算与可见区域；`motion/geometry.ts`：连续片段映射与液态连接几何；`motion/animate-regroup.ts`、`styles/card-morph.css`：GSAP Flip 与 SVG 过渡。装饰层不参与媒体解码和数据持久化。
- `src/shared/canvas/operations.ts`：左右吸附、拼接、拆分及反向操作。
- `src/main/projects/project-database.ts`：在项目 SQLite 事务内验证并保存画布。
- `src/main/projects/project-service.ts`：通过迁移写入闸门访问当前目录，更新项目索引。
- `src/renderer/src/features/workspace/use-canvas-document.ts`：保存状态与撤销历史；失败回读项目并提示。
- `use-card-drag.ts`：拖动过程、吸附预览和取消，移动过程中不写磁盘。
- `project-canvas.tsx`：React Flow 视图组合与选择；保留节点测量尺寸，避免选中时短暂隐藏造成点击丢失。
- `canvas-error-boundary.tsx`：画布渲染／生命周期异常的恢复页，保留顶栏与项目导航；重新加载可清除开发窗口中混用的依赖模块。
- `video-card.tsx`、`canvas-actions.tsx`、`sequence-player.tsx`：卡片、工具条与浮层播放器。
- `playback/sequence-playback.ts`：双播放器轮换、预加载、选择版本与播放生命周期；`prepare-video.ts`：可取消的首帧就绪等待；`use-sequence-playback.ts`：React 挂载及清理。Electron 的隐藏／暂停视频可能不触发 compositor 帧回调；解码完成后还使用两帧绘制等待和 100ms 有界兜底，避免已有画面仍超时。

项目数据库 `metadata.canvas` 存储 `{ version: 1, revision, cards }`。每个卡片分别持有 `position` 和有序 `assetIds`，播放顺序不依赖横坐标。本期每个视频素材在画布中出现一次；以后镜头版本管理会引入独立镜头／片段实体，不能把当前素材 ID 模型直接当作完整剪辑模型。

沿用数据库容器格式 1，画布使用独立版本。旧项目缺少 `canvas` 时，在读取时生成确定的初始排布，不修改原文件；首次操作才写入该键。读取到新视频时在已有卡片下方补入，不改变既有组合。

界面发送受影响卡片的 `before/after`，主进程先比较原状态、检查素材集合完全相同，再原子替换受影响卡片。后到的导入不会被旧画布整份覆盖。过期操作、重复素材、标识冲突、非有限坐标均拒绝；迁移期间拒绝新画布写入，迁移完成后按当前保存目录提交。

## 验证记录与边界

- 预览缓冲新增 12 项自动测试：首帧等待、隐藏窗口回调兜底、加载取消／失败、按序预加载、快速跳段晚到结果、音量／静音／倍速延续、失败重试、回到已播放片段后从头预加载、关闭时取消与自动播放被拒绝。浏览器使用实际预览组件及本地蓝／绿／橙样例，顺次播放与手动跳段的逐帧采样未发现可见播放器缺少已解码帧或两个非静音播放器同时播放；错误素材保留原画面，关闭后两路媒体均暂停并移除来源。此项未测量连续音轨衔接，也不等同于所有编码／设备上的视觉保证。macOS Electron 使用真实本地媒体协议验证首段播放并自动到达第三段，控制台未出现新的运行错误；全屏完整交互、Windows 和安装包仍待验证。

- 首次拼接性能采样：本机浏览器、两个本地样例、实际画布组件与模拟保存 IPC 下，首次观测最大帧间隔 50ms，后续合并／拆分为约 17ms；首次 `Flip.getState`／`Flip.from` 分别约 2.3／5.6ms，后续约 0.4／0.9ms。移除过渡表面的 SVG 阴影滤镜后，一次重新加载采样约 17.6ms；恢复旧阴影做对照约 17.7ms，因此不能把首次停顿唯一归因于滤镜，也不宣称冷启动卡顿已彻底解决。滤镜删除仅用于降低非必要绘制开销，连接形变保留。独立临时 SQLite 项目的 6 次合并保存为 0.66–1.80ms，不含 Electron IPC；上述帧间隔不是 CPU／GPU 耗时，仍缺完整桌面冷启动性能追踪与低配机器验证。

- 项目打开白屏修复：Electron 控制台确认旧版 React DOM 预构建模块与新版 React 模块混用，触发 `Invalid hook call`；完整刷新后从项目列表打开本地示例，三段组合恢复且无新增控制台错误。应用依赖去重／预构建配置后，重启原开发进程再次从首页进入项目，缩略图与播放入口正常。浏览器使用实际 App 与模拟 IPC 注入画布渲染错误，验证恢复页、返回列表后打开正常项目，以及重新加载返回首页。临时回归文件已移除。
